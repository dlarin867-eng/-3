# Бизнес-логика — блок 6 задачника

- `norm-calculator.ts` — стартовая норма КБЖУ (формула Миффлина-Сан Жеора), с жёстким потолком белка (defense-in-depth поверх UX-гейта в `api/routes/users.ts`).
- `carb-cycling.ts` — циклирование углеводов по тренировочным/нетренировочным дням, идемпотентное получение нормы на сегодня + ручной пересчёт при тоггле типа дня.
- `autocorrection.ts` — сравнение фактической динамики веса с ожидаемой для цели раз в 7–14 дней, предложение сдвига калорий (не применяет само — решение "принять/отклонить" на стороне пользователя).
- `reminders.ts` — тайминг вокруг тренировки (предупреждение по углеводам за 1–2 ч до, напоминание о белке после) и вечерняя сводка "не хватает N г белка".

Все четыре — чистые функции без сети/БД, поэтому юнит-тестируются напрямую (`*.test.ts` рядом, см. блок 11 задачника — там же кроссбраузерное/нагрузочное тестирование, здесь только бизнес-логика).
