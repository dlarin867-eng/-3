# Карта скилов — кто чем пользуется

*Каталог Claude Code Skills (`npx skills`, [skills.sh](https://skills.sh/)), присвоенных агентам команды. Собрано через `find-skills` · 21 августа 2026. Установлено на уровне проекта (`.agents/skills`, симлинки в `.claude`) — работает только в этом vault'е «УРОК 1», не глобально.*

Полное описание самих агентов — в [[команда]]. Каждый скил закреплён за агентом прямо в его файле (раздел «Установленные скилы Claude Code»); здесь — сводная таблица, чтобы видеть всю картину сразу.

## Как это работает технически

- Скилы лежат в `.agents\skills\<имя>\` и симлинкаются в `.claude` — Claude Code видит их через инструмент `Skill` (`Skill({ skill: "<имя>" })`), агенту не нужно ничего дополнительно настраивать, кроме упоминания в своей инструкции.
- Установка шла через `npx skills add <владелец>/<репозиторий>@<имя-скила>` — под капотом клонирует GitHub-репозиторий. На этой машине для этого пришлось доустановить Git for Windows (его не было).
- Каждый скил проходит автоматическую проверку риска (Gen/Socket/Snyk) при установке — у всех установленных ниже статус `Safe` / `Low Risk`, кроме одного `Med Risk` (`web-design-guidelines` — 0 alerts у Socket, риск общий, не блокирующий) и одного отклонённого (см. «Что не взяли»).

## Ниже порога доверия — использовать с осторожностью

По правилам `find-skills` (шаг 4 — «Verify Quality Before Recommending») скилы с 1K+ установками — предпочтительны, с <100 — под сомнением. Три скила ниже здесь не дотягивают до 1K, но были единственными релевантными вариантами в своей теме:

- **`roadmap-prioritization`** (product-lead) — 195 установок.
- **`seo-strategy`** (growth-marketer) — 171 установка.
- **`performing-threat-modeling-with-owasp-threat-dragon`** (security-reviewer) — 175 установок, автор без явной репутации. Пользователь осознанно согласился поставить его с пометкой «проверить» — при первом реальном использовании стоит перечитать сам SKILL.md, прежде чем полагаться на его инструкции.

## Что не взяли

- **Распознавание еды по фото для backend-developer.** Искали скилы под «Claude API vision / structured output / OCR» — ничего с достаточной репутацией и явной релевантностью к продуктовому кейсу (распознавание блюда, а не документов/чеков) не нашлось. `backend-developer` продолжает работать по своему разделу «Рекомендуемые скилы» (неформальный) в собственном файле.
- **`fearovex-labs/agent-config@image-ocr`** — установка упала с ошибкой авторизации (репозиторий фактически приватный/недоступен), несмотря на видимость в поиске.
- **`linkfox-ai/linkfox-skills@linkfox-multimodal-recognize-image`** — установился, но Socket пометил его `Med Risk / 1 alert`, а по содержанию репозиторий оказался e-commerce-тулкитом (1688/Amazon), не специализацией на еде — удалён сразу после установки.

## Дальше

- Если добавятся новые агенты или сменится специализация — обновляй и эту карту, и раздел «Установленные скилы Claude Code» в файле агента одновременно.
- Обновление скилов: `npx skills update` (из корня проекта — они установлены на уровне проекта, не глобально).
- Полный список установленного: `npx skills list`.
