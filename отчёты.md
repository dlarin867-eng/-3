# Отчёты агентов

*Короткий отчёт сразу после того, как агент закончил задачу — сам или получив результат от делегированного субагента. Пишут «главные» агенты — [[product-lead]], [[backend-developer]], [[frontend-developer]], [[qa-devops]] (у них есть право делегировать через `Agent`, см. [[команда]], раздел «Субагенты»). Остальные агенты не дублируют сюда каждый чих — если задачу вёл один из специалистов напрямую без делегирования, отчёт даёт тот, кто её вёл.*

*Не путать с [[журнал]] (хронологический дневник сессий целиком — что происходило и почему, веду я) и [[задачник]] (чек-лист ✅/❌ по блокам — текущий срез статуса). Здесь — что конкретно сделал агент по конкретной задаче. Новая запись — сверху.*

**Шаблон записи:**
```
## ГГГГ-ММ-ДД · Агент
**Задача:** ...
**Сделано:** ...
**Файлы/результат:** ...
**Что дальше / нужно от фаундера:** ...
```
